# Embedded C with STM32

Cairo University coursework in microcontroller programming and hardware interfacing. The featured project is an [STM32 ADC driver and temperature display](ADC-Driver-main/), with C source, peripheral drivers, and a Proteus simulation.

The [lab assignments](Lab_1%20Assignment/) contain smaller exercises. For the related hardware-interfacing collection, see [Embedded-C](https://github.com/MohamedMostafa23/Embedded-C).
